# 💰 Cotizador con Prototypes

Aplicación web interactiva desarrollada como parte del curso **JavaScript Moderno: Guía Definitiva Construye +10 Proyectos**.

El proyecto consiste en un cotizador dinámico que permite seleccionar diferentes opciones y calcular un precio final, utilizando **JavaScript y Prototypes** para aplicar conceptos de Programación Orientada a Objetos.

## ✨ Funcionalidades

- Selección de diferentes opciones para realizar una cotización.
- Cálculo dinámico del precio.
- Actualización del resultado en función de las opciones seleccionadas.
- Validación de los datos ingresados.
- Interacción dinámica con la interfaz.
- Generación de una cotización final.

## 🚀 Instalación

Clona el repositorio:

```bash
git clone https://github.com/cristhianychr/cotizador-prototypes-js.git
```

Ingresa al proyecto:

```bash
cd cotizador-prototypes-js
```

Abre `index.html` en tu navegador.
